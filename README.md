# 绿皮漫游 · 中国环线规划器

一个单文件网页应用：以任意城市为起点，规划中国铁路旅行环线，并估算全程耗时与穷游花费。

## 功能特点

- **自由切换出发地**：281 座城市可选（含国际线路），闭合环线自动返回起点
- **两种交通模式**：纯绿皮火车（Z/T/K）与高铁/混乘，一键切换对比
- **经典环线模板**：西南山水、丝路雪域青藏、江南古都、纵贯南北、河西走廊 + 南疆丝路、中原古都 + 华东穷游、丝路中亚免签、贝加尔湖 + 海参崴免签，或自定义自由环线
- **中文地图**：Leaflet 地图展示环线站点与城市景点，可切换各城市展示的著名景点
- **时间与花费估算**：
  - 席别、食宿档次（极致穷游 / 轻穷游 / 舒适自由行 / 品质度假）、出行人数、学生票、跨夜车省宿、仅玩免费景点
  - 按国铁递远递减规则估算逐段票价与耗时
  - 费用结构图表（Chart.js）
- 全部数据内置于单一 HTML 文件，打开即用

## 使用

直接用浏览器打开 `index.html` 即可（建议 Chrome / Edge）。

> 页面依赖 CDN 资源（Tailwind CSS、Leaflet、Chart.js、Lucide、Google Fonts），需要联网。

## 技术栈

- HTML + 原生 JavaScript（单文件，无构建步骤）
- Tailwind CSS 3.4（CDN）
- Leaflet 1.9.4（地图）
- Chart.js 4.4.1（图表）
- Lucide 0.460（图标）
